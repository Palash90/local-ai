## 5. The thermal triad (the day's biggest discovery)

Three independent governors, identical symptom (slow tok/s), different sensors:

| # | Governor | Sensor | Actuator | Signature |
|---|---|---|---|---|
| 1 | RAM evacuation (our code) | `free` vs threshold | kill-all + requeue + resume | `[ram]` logs, `requeued` state |
| 2 | Thermal protection (firmware) | `acpitz` ~96°C package | dGPU squeeze 35W → 10W, 210MHz clocks | silent; only `nvidia-smi -q -d POWER` + tg collapse (18 → 2.5 tok/s, exactly 7.3x clocks ≈ 7.2x throughput) |
| 3 | Power-state mgmt (EC/firmware) | AC vs battery | battery-mode caps, latch across replug | stuck 10W while cool; `powerprofilesctl`; silent fans on battery |

Evening timeline: unplug episodes (twice) → latched quiet state + sustained 26B CPU-expert load (~400% Ryzen) → 96°C package → 10W clamp → tg 2.5. Self-recovered on cooldown (35W restored → EC exonerated, no reset needed). Machine: ASUS Vivobook M6500QC, BIOS 2023 (no recent flash; fwupd only CA certs) — firmware-change hypothesis ruled out by self-restoring cap. Fans verified working (6000+4200 RPM on cooldown).

Corollary: every tok/s figure from unplugged/hot/capped windows is void. Voids stacked three deep (battery → heat → power-cap).
